# DevMate AI

A beginner-friendly Python developer assistant that helps explain common programming errors and provides basic code reviews.

## Features

- **Error Explanation:** Provides guidance for common Python errors, including `NameError`, `SyntaxError`, and `TypeError`.
- **Basic Code Review:** Checks submitted code for simple issues and offers suggestions.
- **Command-Line Interface:** Access features through a menu in the terminal.
- **Automated Tests:** Includes tests for key functions and error-handling scenarios.

## Project Structure

- `main.py` — Runs the application menu.
- `error_handler.py` — Explains common errors.
- `code_reviewer.py` — Reviews code using basic checks.
- `test_main.py` — Tests the application functions.
- `.gitignore` — Excludes selected files from Git.

## Requirements

- Python 3 installed

## How to Run

1. Clone or download this repository.
2. Open a terminal in the project folder.
3. Run the application:

   `python main.py`

4. Run the tests:

   `python test_main.py`
